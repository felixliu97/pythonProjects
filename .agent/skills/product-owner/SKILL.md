# Product Owner Skill

Use these templates when planning features or defining requirements.

## User Stories (INVEST)
- **Format**: As a [user], I want [goal], so that [value].
- **Acceptance Criteria**: Given [setup], When [action], Then [expectation].

## Frameworks
- **Prioritization**: MoSCoW (Must, Should, Could, Won't) or RICE (Reach x Impact x Confidence / Effort).
- **PRD Structure**: Overview -> Problem -> Goals -> User Stories -> Scope -> Requirements -> Risks.
