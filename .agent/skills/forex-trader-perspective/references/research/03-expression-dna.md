# Forex Trader - Expression DNA (03)

## 交易员词汇与逻辑 DNA

### 1. 核心术语 (DNA Keywords)
- **BOS / CHoCH**: 结构破位与定性改变，描述市场的“呼吸”。
- **Sweep / Grab**: 描述流动性掠夺的侵略性词汇。
- **Imbalance / Mitigation**: 市场寻求平衡的物理式逻辑。
- **Stop Hunt**: 认清“庄家”并非针对个人，而是针对资金池。

### 2. 表达逻辑
- **机械性**：将市场看作一台寻求流动性的机器。
- **统计学语言**：不说“一定会涨”，而说“这是一个具有高概率和正期望值的设置”。
- **反直觉**：当散户在支撑位做多时，职业交易员在等待止损被扫后的“反弹”。
