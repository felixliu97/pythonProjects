## 机构级「暴涨股生命周期五阶段模型」

几乎所有历史上的"10×股"——无论是 Tesla Inc.、NVIDIA Corporation、Pilbara Minerals Limited、Pro Medicus Limited，还是 Wisetech Global Limited——都遵循非常一致的成长路径模型。

### 一、暴涨股的五个阶段

#### 阶段1：无人关注期（Valuation Floor）

**特征：**
- 市值小（常见 < $300M）
- 无收入 / 收入很低
- 项目未投产
- 市场不相信能成功
- 经常CR（融资）

**典型表现：**
- 股价长期横盘甚至阴跌

**机构行为：**
- 只有 early-stage VC、resource funds、small-cap hedge 在布局

**ASX典型例子：**
- Deep Yellow Limited
- Boss Energy Limited（2020年前）
- Pilbara Minerals Limited（2016年前）

**这是：**赔率最大阶段，但成功率最低

#### 阶段2：验证突破期（Proof-of-Concept）

**核心变化：**市场开始相信——不是故事，是现实

**触发因素通常包括（其中之一即可）：**

| 板块类型 | 触发因素 |
|---------|---------|
| **资源股** | DFS完成、Offtake签约、建厂融资完成 |
| **科技股** | 大客户签约、ARR快速增长、产品进入商业化 |
| **医疗股** | FDA批准、商业订单落地 |

**典型表现：**股价上涨 2×～5×

**例子：**
- Pilbara Minerals Limited（锂矿投产前）
- Pro Medicus Limited（美国医院合同阶段）
- Wisetech Global Limited（CargoWise全球扩张阶段）

**这是：**确定性开始出现阶段

#### 阶段3：现金流确认期（Institutional Entry Phase）

**关键变化：**开始赚钱（或接近赚钱）

**典型指标：**
- 收入增长 > 50%
- 毛利率明显高于行业平均
- 长期合同客户
- 现金流开始转正

**机构行为：**
- 真正的大资金进入：super funds、global funds、ETFs

**股价表现：**再涨 3×～10×

**例子：**
- NVIDIA Corporation（数据中心业务爆发）
- Tesla Inc.（Model 3量产成功）

**这是：**最稳定的主升浪阶段

#### 阶段4：行业统治期（Market Leadership Phase）

公司变成：行业标准，或者行业基础设施

**典型表现：**
- 竞争对手消失
- 利润率提升
- 市场份额扩大
- 定价权出现

**例子：**
- Wisetech Global Limited
- Pro Medicus Limited
- Xero Limited

**股价表现：**继续上涨但速度下降

#### 阶段5：估值溢价期（Narrative Premium Phase）

**市场逻辑变化：**不是看利润，而是看想象空间

**典型估值：**
- PE 80+
- PS 20+

**机构行为：**开始分歧

**表现：**波动变大

**例子：**
- Tesla Inc.（2021）
- NVIDIA Corporation（2024）

**这是：**后期阶段

### 二、所有暴涨股都有的5个共同特征

机构选股最核心五条：

#### ① 行业必须是超级赛道

例如：
- AI
- 锂
- 能源转型
- 云软件
- 医疗影像

没有行业风口，几乎不可能10×。例如传统制造几乎不会出现。

#### ② 公司必须有"唯一性"

例如：
- 技术壁垒
- 资源储量优势
- 网络效应
- 规模优势

**例子：**
- **Pro Medicus Limited**：全球影像云领先
- **Pilbara Minerals Limited**：低成本锂矿资源

#### ③ 必须经历一次"市场不相信"

10×股早期一定被质疑：
- 贵
- 骗局
- 吹牛
- 不现实

**例如：**Tesla Inc.曾被华尔街长期做空

#### ④ 必须经历资金洗盘阶段

**表现：**
- CR
- 回撤40%
- 回撤60%
- 横盘2年

**例子：**Pilbara Minerals Limited 2018–2020 横盘，之后暴涨

#### ⑤ 必须有连续催化剂

暴涨股不是靠一个利好，而是：**催化剂链条**

**典型顺序：**

| 资源股 | 科技股 |
|--------|--------|
| 资源确认 → 融资 → 建厂 → 投产 → 扩产 | 产品 → 客户 → 收入 → 盈利 → 全球扩张 |

### 三、应用于ASX催化剂选股

使用本框架对 `config/asx_catalysts.yaml` 中的标的进行阶段定位：

| 阶段 | 选股策略 | 关注指标 |
|------|---------|---------|
| 阶段1 | 小仓位布局，分散押注 | 资源量、融资完成度、现金储备 |
| 阶段2 | 验证后加仓 | DFS完成、合同签约、商业化里程碑 |
| 阶段3 | 机构资金入场，主升浪 | 收入增长>50%、毛利率、ARR增长 |
| 阶段4 | 持有享受垄断溢价 | 市场份额、定价权、利润率扩张 |
| 阶段5 | 警惕估值回调，考虑减仓 | PE/PS估值、机构持仓分歧、波动率 |

> **核心原则：** 不同阶段的标的需要不同的仓位管理和止损策略。阶段1需要严格止损，阶段3可以承受更大回撤。

### 四、阶段交易策略（买点 / 卖点 / 仓位管理）

#### 阶段1：无人关注期

| 维度 | 策略 |
|------|------|
| **买点** | CR（融资）完成后股价企稳；关键审批/资源确认公告前低吸；管理层增持信号 |
| **卖点/止损** | 融资失败或被稀释超预期 → 立即止损；现金 runway < 6 个月且无融资计划 → 清仓；硬止损 -20% |
| **仓位** | 极小仓 1-2%，分散 3-5 个标的押注；总敞口不超过组合的 10% |
| **心态** | 做好归零准备，赔率大但成功率低；不加仓摊薄，等验证信号 |

#### 阶段2：验证突破期

| 维度 | 策略 |
|------|------|
| **买点** | DFS/临床数据验证成功后的首次回调（通常 -10~20%）；Offtake/大客户合同签约确认日；建设融资 close 公告后 |
| **卖点/止损** | 验证失败（DFS 经济性不达标 / 临床主要终点未达 / 合同取消）→ 立即止损；项目延期超 6 个月 → 减半仓；硬止损 -15% |
| **仓位** | 中等仓 3-5%；验证通过后可从阶段1加仓至此水平；分批建仓（验证前 1/3，验证后 2/3） |
| **心态** | 确定性开始出现，但仍需纪律；关注"验证 → 资金 → 建设"链条是否断裂 |

#### 阶段3：现金流确认期

| 维度 | 策略 |
|------|------|
| **买点** | 季报超预期后的技术性回调；机构增持（substantial holder notice）；行业利好催化（商品价格暴涨 / 政策扶持） |
| **卖点/止损** | 收入增速连续两季放缓至 < 30% → 减仓 1/3；毛利率环比下滑 > 5pp → 警惕；硬止损 -10%（此阶段回撤容忍度更高） |
| **仓位** | 重仓 5-10%；这是主升浪，允许持有穿越波动；可用 trailing stop 保护利润（如从高点回撤 -15% 触发） |
| **心态** | 最稳定的赚钱阶段，核心是"拿住"；不要因短期波动被洗出 |

#### 阶段4：行业统治期

| 维度 | 策略 |
|------|------|
| **买点** | 行业逆风导致的恐慌性回调（如商品周期低谷）；竞争对手退出 / 并购整合带来的份额提升 |
| **卖点/止损** | 市场份额被新进入者侵蚀 → 逐步减仓；管理层重大变动 / 战略方向转变 → 重新评估；增速降至个位数 → 转为收息持有或退出 |
| **仓位** | 持有为主 5-8%，不追高不加仓；享受分红和回购带来的复利 |
| **心态** | 公司已成为行业基础设施，波动降低但上涨空间也有限；重点关注护城河是否被侵蚀 |

#### 阶段5：估值溢价期

| 维度 | 策略 |
|------|------|
| **买点** | **不建议新建仓**；若已持有从前期阶段，继续持有但不加仓 |
| **卖点/止损** | PE > 80× 且增速放缓 → 分批止盈（每涨 20% 卖出 1/4）；机构持仓出现净减持 → 加速退出；市场情绪过热（媒体头条、散户蜂拥）→ 反向信号 |
| **仓位** | 逐步减至 2-3%；用期权对冲下行风险（如有）；锁定利润为第一优先级 |
| **心态** | 这是收割阶段，不是播种阶段；贪婪是最大的敌人 |

> **跨阶段通用规则：**
> 1. 永远不要在单一标的上超过组合的 10%
> 2. 阶段升级（如从1→2）是加仓信号，阶段降级是减仓信号
> 3. 止损纪律优先于个人判断——触发即执行，不犹豫
> 4. 每次交易前写下买入理由和预设卖出条件

### 五、阶段1→2 的「惊险跳跃」— 会计与审计视角

阶段1到阶段2是整个生命周期中**成功率最低、但赔率最高**的转折点。

#### 财务报表特征

- 阶段1公司的审计报告通常附有 **Going Concern（持续经营）** 警示
- 现金流量表以融资活动为主，经营现金流持续为负

#### CR（融资）的质量判断

**并非所有融资都是坏事。** 机构看重的是融资的质量：

| 正面信号（阶段2信号弹） | 负面信号（阶段1.5 死亡陷阱） |
|------------------------|---------------------------|
| 一级梯队投行背书（Macquarie, Canaccord, Bell Potter） | 无名小券商包销或自行配售 |
| 融资价格溢价或小幅折价（< 10%） | 大幅折价（> 20%）且附带大量 Options |
| 机构投资者主导认购 | 散户为主的 SPP（股东购买计划） |
| 融资用途明确（建设/商业化） | 融资用于"运营资金"（Working Capital） |

#### "阶段1.5" 死亡区

很多资源股会死在阶段1.5：DFS（可行性研究）虽然过了，但最终**无法获得项目融资（Project Financing）**。

关键观察：DFS 完成后 6-12 个月内是否有 Offtake 合同或 Project Finance 进展，没有则大概率回落。

### 六、阶段3 财务确认指引 — Operating Leverage（经营杠杆）

#### 核心指标

当一家公司进入阶段3，最值得关注的单一指标是 **Operating Leverage**：

> 当收入增长 50% 时，管理费用（G&A）和研发费用（R&D）仅增长 10%-20%

#### 意义

这证明了商业模式的**可扩展性**（Scalability）。一旦跨过盈亏平衡点，每增加一分钱收入，几乎 80% 都是净利润。

**这才是机构疯狂抢筹、推高 PE 的根本原因。**

#### 典型案例

- **Pro Medicus (PME)**：影像 SaaS 模式，边际成本趋近于零。一旦跨过盈亏平衡点，利润率飙升
- **Wisetech (WTC)**：物流云平台同理，客户越多，单位成本越低

#### 财务验证清单

| 指标 | 阶段3确认信号 |
|------|-------------|
| 收入增速 | > 50% YoY |
| 毛利率 | 高于行业平均且稳步扩张 |
| G&A / Revenue | 逐季下降 |
| 经营现金流 | 转正或接近转正 |
| 客户集中度 | 前5大客户占比 < 50%（降低风险） |

### 八、机构筛选隐藏项 — Capital Structure（资本结构）

在 ASX 寻找 10× 股，除了基本面和催化剂，还有一个经常被忽视的隐藏特征：**干净的资产负债表**。

#### 避坑指南

| 风险信号 | 影响 |
|---------|------|
| 大量 Convertible Notes（可转债） | 转股时造成巨大抛压 |
| 极高比例的 Options / Warrants（期权/认股权证） | 股价上涨过程中持续面临 Overhang（悬挂供给） |
| 频繁低价 CR + 附带免费 Options | 持续稀释，早期股东深度套牢 |

#### 加分项

| 正面信号 | 意义 |
|---------|------|
| 创始人持股 > 15% | 利益绑定，不会轻易稀释 |
| 近期 On-market Buy（二级市场增持） | 内部人用真金白银投票 |
| 无可转债、Options 占总股本 < 10% | 上涨时无抛压，筹码结构干净 |

### 九、防守清单 — ASX 高波动市场生存法则

五阶段模型是**进攻手册**，以下是配套的**防守清单**：

#### ① 现金耗尽率（Cash Burn Rate）

账上的钱够不够撑到下一个催化剂？

- 阶段1标的：至少需要 12 个月 Cash Runway
- 阶段2标的：至少需要 18 个月或已锁定项目融资

#### ② 管理层履历

CEO 是否有把公司从 Exploration（勘探）带向 Production（投产）的**成功记录**？

> 带队的人往往决定了能否跨越阶段2。

#### ③ 板块轮动风险

组合高度集中在能源和生物医药时，需警惕**单一宏观因素的共振风险**：

- 利率变动对 Biotech 估值的冲击
- 美元走势对大宗商品价格的影响
- 政策变化（如澳洲资源税、FDA 审批标准调整）

#### ④ 交易纪律核查

每月自检一次：

- [ ] 单一标的占比是否超过 10%？
- [ ] 所有阶段1持仓是否都设了硬止损？
- [ ] 现金储备是否足够应对 2 次以上的加仓机会？
- [ ] 是否有标的已触发卖出条件但未执行？

### 十、名单深度解析 — 机构筛选的核心差异

#### 1. BOT / CU6：阶段2→3 的「生死跨越」

机构最愿意在**确定性出现的瞬间**下重手。

- **BOT**：FDA 批准已解决最大的科学风险，接下来 12 个月是验证"能不能赚钱"的财务确认期。如果毛利数据亮眼，将迅速进入阶段3，迎来 Super Funds 暴力建仓
- **CU6**：同属"科学风险已解除、商业化待验证"的窗口期。Phase III 数据读出 + FDA 递交是下一个关键门槛

> **核心逻辑：** 阶段2→3 的跨越速度取决于首批商业化数据的质量。毛利率 > 行业平均 = 阶段3确认。

#### 2. DEL：身份重塑（Re-rating）逻辑

市场过去把 DEL 看作**低毛利的建筑公司（EPC）**，但随着生物质能电厂投产，机构会重新切换估值模型：

| 旧估值框架 | 新估值框架 |
|-----------|-----------|
| EPC 建筑承包商 | 能源基础设施 / 绿色公用事业 |
| PE 8-12× | PE 25×+ |
| 一次性项目收入 | Recurring Revenue（经常性收入） |

**催化节点：** 当 Recurring Revenue 占总收入比例突破 30%，Re-rating 将加速。

#### 3. 资源股（TM1, LOT, DYL）的「资本密集型」陷阱

这些公司正处于阶段2。机构目前关注的**不是"矿在哪里"，而是"钱在哪里"**。

- **TM1**：引入美股挂牌及大宗能源基金后，其阶段2→3 的跨越速度可能比纯 ASX 标的快得多（双市场流动性 + 更广的机构触达）
- **LOT / DYL**：铀矿标的高度依赖现货价格。项目融资（Project Financing）的落地是唯一的阶段升级信号

> **资源股通用规则：** DFS 完成后，12 个月内必须看到 Offtake + Project Finance 进展，否则大概率回落至阶段1。

### 十一、风控建议 — 财务会计视角

#### ① 警惕阶段4 的「估值天花板」

像 DRO 这类已经大幅上涨的行业标杆，PS 已经不低。除非能证明自身具备像 WTC (Wisetech) 那样的**定价权（Pricing Power）**，否则很难再翻 10×，更多是阶段性盈利增长。

**判断标准：**
- 是否有长期合同锁定价格上调机制？
- 客户转换成本是否足够高？
- 竞争对手能否在 2-3 年内复制其产品？

如果三个问题中有两个答案为"否"，则大概率停留在阶段4，不会进入阶段5。

#### ② 盯死 2026 年底财务报表

重点关注阶段3潜力股的 **Operating Cash Flow (OCF)**：

| 情景 | 信号 | 行动 |
|------|------|------|
| 收入涨 + OCF 转正 | 阶段3确认 | 加仓 / 持有 |
| 收入涨 + OCF 仍为负 | 可能面临再次 CR | 减仓 / 设紧止损 |
| 收入涨 + OCF 负 + 无融资计划 | 阶段2平台期无限期拉长 | 清仓 |

> **关键日历：** 2026 年 8-9 月（FY26 年报季）和 2027 年 2 月（半年报季）是验证窗口。提前布局，报表发布后 48 小时内决策。

### 1. AGR.AX：基于机构成本与基本面的套利

*   **操作路径**：

### 4. DEL：基本面正确但入场过早 (时机与流动性)
